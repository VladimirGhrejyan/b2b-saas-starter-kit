# Cursor AI Configuration

This directory contains Cursor-specific AI assistance configuration for this Nx workspace.

## Structure

```
.cursor/
└── skills/           # Nx workspace skills for Cursor AI
    ├── nx-workspace/         # Explore projects, targets, dependencies
    ├── nx-generate/          # Scaffold apps and libraries
    ├── nx-run-tasks/         # Run build, test, lint tasks
    ├── nx-plugins/           # Discover and add Nx plugins
    ├── link-workspace-packages/  # Link monorepo packages
    ├── nx-import/            # Import external projects
    └── monitor-ci/           # Monitor and fix CI with Nx Cloud
```

## Skills Overview

### Core Nx Skills

**nx-workspace** - Workspace exploration and understanding

- List projects in the workspace
- Get project configuration and targets
- Query dependencies between projects
- Understand the project graph
- Use when: exploring the workspace, understanding project structure, debugging configuration

**nx-generate** - Code scaffolding and generation

- Generate new applications (NestJS, React + Vite)
- Create shared libraries
- Scaffold features and components
- Use generators from Nx plugins
- Use when: creating new projects, scaffolding code, setting up structure

**nx-run-tasks** - Task execution

- Run builds, tests, lints
- Execute tasks on multiple projects
- Use affected commands
- Use when: building, testing, running any Nx tasks

**nx-plugins** - Plugin management

- Discover available Nx plugins
- Install new plugins for frameworks
- Use when: adding support for new technologies

### Monorepo Skills

**link-workspace-packages** - Package dependency management

- Link workspace packages using PNPM
- Add dependencies between monorepo packages
- Fix "Cannot find module" errors for workspace packages
- Use when: wiring up dependencies, fixing import resolution

**nx-import** - Project migration

- Import external repositories into the workspace
- Preserve git history during imports
- Migrate from other monorepo tools (Turborepo, etc.)
- Use when: bringing external projects into the monorepo

### CI/CD Skills

**monitor-ci** - Continuous Integration monitoring

- Monitor Nx Cloud CI pipelines
- Handle self-healing CI fixes
- Apply automated fixes for failed CI runs
- Requires: Nx Cloud connection
- Use when: tracking CI status, fixing CI failures

## How Skills Work

Skills are automatically discovered by Cursor on startup. Each skill:

- Has a `SKILL.md` file with YAML frontmatter defining when to use it
- Contains detailed instructions for the AI agent
- May include reference documents and scripts
- Is scoped to this project (not global)

## Usage

You don't need to do anything special. When you ask Cursor to perform tasks related to Nx, it will automatically invoke the relevant skills.

Examples:

- "Show me all projects in the workspace" → Uses `nx-workspace`
- "Create a new React library called shared-ui" → Uses `nx-generate`
- "Build only the projects that changed" → Uses `nx-run-tasks`
